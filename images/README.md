# Images Folder

Place your images here. Images in the `public/images/` folder can be referenced in your React components using:

```jsx
<img src="/images/your-image.jpg" alt="Description" />
```

## Notes

- Images in the `public` folder are served statically
- Use the path `/images/filename.jpg` (note the leading slash)
- Supported formats: JPG, PNG, GIF, SVG, WebP
- For best performance, optimize images before adding them
